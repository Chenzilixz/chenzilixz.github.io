# 多时间尺度储能协同规划与可解释分析平台

本仓库用于 GitHub Pages 免费托管。20 个网页文件与原公开版的发布文件逐字节相同，保留全部页面、模型、图表、文件上传、分析记录和导出功能。

每位访客在自己的浏览器导入 Excel/CSV，独立训练模型并计算 Tree SHAP。数据集、分析记录和结果保存在当前浏览器的独立工作区；用户文件不发送至托管服务器。内置 2400 组独立生成的合成演示样本，没有上传原始研究数据。

主要功能：14 项输入与 10 项输出映射、工作表与阶段筛选、梯度提升/随机森林/极端随机树、经济性与低碳性解释、重要性/蜂群/依赖/热力/瀑布/原生力图/决策路径、模型诊断、方案对比、PNG 与离线 HTML/ZIP 导出。

使用浏览器地址打开平台即可。页面更新或关闭发布者电脑不影响已托管网页；实际访问与使用仍受网络连接、浏览器权限及本机计算资源影响。更换网址后，旧网址的浏览器本地工作区不会自动转移，需要重新导入数据。

来源仓库：https://github.com/Chenzilixz/multitimescale-energy-storage-planning-explainable-analysis
